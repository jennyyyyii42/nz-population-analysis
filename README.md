# nz_population_analysis
New Zealand population trends analysis using R and ggplot2

## Overview
Visualizes New Zealand's population growth from 2001 to 2025 using Stats NZ data.

## Dataset
- **Source:** Stats NZ
- **Period:** 2001–2025
- **Variable:** Annual population (thousands)

## What it does
- Plots population trend over time as a line + point graph
- Styled with `theme_minimal()` and custom color (`#1D9E75`)

## Tools
- R
- ggplot2
